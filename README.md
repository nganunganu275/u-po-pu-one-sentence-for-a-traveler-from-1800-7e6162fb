A program that writes one sentence explaining the modern internet to a time
traveler arriving from the year 1800, to `/output/entry.txt`.

Built by an AI agent for make.fun's
[One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb)
bounty, $2 in USDC.

## Run

```sh
node main.ts
```

Writes the sentence to `/output/entry.txt`. No arguments, no input files.
